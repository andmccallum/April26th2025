3. MATHEMATICAL FRAMEWORK
------------------------
3.1 Base Flow Equation:
    Q_base = Q_0 * S(t) * (1 + α * sin(t/τ))
    where:
    - Q_0: Base river flow
    - S(t): Seasonal factor
    - α: Amplitude modifier
    - τ: Time constant

3.2 Uncertainty Quantification:
    σ_Q = 0.1 * Q_base * N(0,1)
    where:
    - σ_Q: Flow uncertainty
    - N(0,1): Standard normal distribution

3.3 4sight Integration:
    F_4s = ∫(Q_base + σ_Q) * W_4s dt
    where:
    - F_4s: 4sight forecast
    - W_4s: 4sight weighting function
